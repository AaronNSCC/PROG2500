# Lab 4 starter: Grade Tracker

Open `GradeTracker.sln` in Visual Studio and run it before you change anything.
Add a few students, select one and remove it, and watch the summary update.
That's the behaviour you need to keep.

Everything is in `MainWindow.xaml.cs` right now. The handout walks you through
moving it to MVVM in five steps. Search the whole solution for `TODO`
(Ctrl+Shift+F) to see where each step happens.

`Commands/RelayCommand.cs` is finished. You don't need to change it.
